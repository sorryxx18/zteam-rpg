# 犀牛搶水源｜自由探索試玩

試玩入口：https://sorryxx18.github.io/zteam-rpg/
獨立專案：https://github.com/sorryxx18/zteam-rpg

目前先測角色在真實街區自由走動，**尚未加入消防栓、火警或搶占水源規則**。不修改原本兩版遊戲或 Z-TEAM 正式站。僅供遊戲，不得作為搶救圖資。

## 開始與操作

1. 進入後先選男隊員、女隊員或犀牛，再選九個分隊之一。
2. 按「開始探索」才進地圖。音樂也在這次手勢後嘗試啟動；手機若擋播放，可點音樂按鈕重試。
3. 電腦用方向鍵／WASD 移動，按住 Shift 或空白奔跑。手機左下搖桿控制方向與走路幅度，右下「跑」必須按住並同時推搖桿才跑；不採自動跑或切換跑。搖桿與跑鍵內縮，避開螢幕邊緣與系統手勢區。放開跑鍵恢復走路，放開搖桿即停。
4. 位置提示顯示目前附近道路與出發點的相對位置，小地圖標出自己；「轄區地圖」查看整區道路及九分隊位置。
5. 「重新選擇」返回開場；⌂ 回本次出發點；＋／− 縮放。
6. 音樂可切換「街角散步」「整裝出發」「夜巡微光」或靜音。三段為程式合成的原創復古晶片音樂，無外部音樂下載／付費 API。

世界座標一單位視為一公尺，既有街區座標不縮短。全推搖桿時步行 **1.4 m/s**、按住跑步 **3 m/s**；半推慢走、斜向不加速。三角色共用 **0.32 m** 碰撞半徑，原圖集顯示高度設為 **1.8 m**，是像素角色尺度而非真人測繪身高。鏡頭拉近維持辨識度；縮放只改觀看範圍，不改地圖距離或走跑速度。

正常 10／20／60 FPS 的同時間位移必須一致；每次移動拆小步避免穿牆。超過 0.25 秒的卡頓受限處理，背景切回不追趕位移，避免瞬間飛走。圖資及設定速度不是實地測量或消防裝備負重跑測數據。

## 本機與部署

不需 npm、建置、外部字體或 CDN。模組與相對 JSON 必須以 HTTP 開啟：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

開啟 `http://127.0.0.1:8766/`。推送 `main` 後，GitHub Actions 執行測試並將靜態檔案發布 Pages。所有資源均用相對路徑，支援專案子目錄。

## 圖資、角色與聲音

- `data/base.json` 為 500 公尺地格索引、分隊及地標；`data/c/X_Y.json` 為真實道路、建物、公園與樹木。座標 x 向東、y 向北，畫面反轉 y。
- 進場讀附近九格，跨格再更新；去重進行中的請求，快取最多 25 格。未載入／無資料的地格不允許進入，讀取失敗可重新整理。
- `data/overview.json` 由 `python3 tools/prepare_overview.py` 產生，只去重既有道路，不新增假道路或分隊。主視圖使用真實建物輪廓碰撞，拆成小步並限制 dt，避免卡頓穿牆。
- 原三角色圖集保持不變：`assets/male.png`、`female.png`、`rhino.png`。各為三欄四行，每格 64×80；行序下／左／右／上，腳底 y=76。`assets/originals/` 保存原圖。
- `music.mjs` 用 Web Audio 在使用者手勢後啟動，提供小音量循環、切歌、靜音及背景頁面暫停；不保證裝置靜音模式下仍能發聲。
- 圖資 © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)，依 ODbL 原始資料授權使用。無外部地圖 API 或分析追蹤。

## 驗證

```sh
node --test tests/*.test.mjs
node --check game.js
node --check music.mjs
```

核心與新行為以逐項 RED → GREEN 開發。最終可玩驗收另以 Chrome 原生長按鍵盤／觸控操作，確認開場不自動移動、三角色及九分隊可開始、速度上限、放開停止、全區定位、音樂訊號／切歌／靜音，以及手機直式／橫式畫面。瀏覽器手機尺寸模擬不等於實體手機效能或喇叭驗收。

`window.__game.getState()` 提供唯讀狀態供 QA；`renderScene()` 僅重畫，沒有傳送座標或修改遊戲狀態的公開入口。不得以受控改座標冒充實際走動。
