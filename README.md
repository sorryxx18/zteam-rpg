# 犀牛搶水源 v3

**3分鐘內佔越多消防栓越好；10秒後其他消防車會來搶。**

## 怎麼玩

選角色、出發分隊與難度，接到火警後前往附近消防栓。每局取火場300公尺內最近15個，只有10～14個就用實際數量；不足10個的場所不出題，不擴圈或補假點。

- 電腦：方向鍵／WASD走路，Shift或空白奔跑。
- 手機：左搖桿走路，同時按住右側跑鍵才奔跑。
- 走到消防栓3公尺內開始佈線，完成才算佔領。每20公尺一條水帶，每條0.5秒，施工最多6秒；可取消，但進度不保留。
- 簡單2台、普通3台、困難4台消防車；10秒後從火場250～300公尺外的道路分方向進場，也要走真實道路及佈線，不會瞬間插旗。
- 黃色是未佔領、綠旗是自己、灰旗是其他消防車；消防車前往的目標閃紅框。
- 設定可關音樂，轄區地圖可看位置；兩者都不會暫停倒數。開場及結算保留「回 Z-TEAM 勤務模擬」。
