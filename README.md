# 犀牛搶水源 v3.2e

**三分半鐘與消防車比佔領顆數，5秒後對手出動，消防栓分四波增援。**

## 怎麼玩

選角色、出發分隊與難度，接到火警後前往附近消防栓。開局開放火場300公尺內最近10個；30、60秒各從300～400公尺新增最多4個，90、120秒各從400～500公尺新增最多4個，總計最多26個。不足就用實際數量，不補假點；一律打滿210秒。

- 電腦：方向鍵／WASD走路，Shift或空白奔跑。
- 手機：左搖桿走路，同時按住右側跑鍵才奔跑。
- 走到消防栓3公尺內開始佈線，完成才算佔領。每20公尺一條水帶，每條0.5秒，施工最多6秒；可取消，但進度不保留。
- 簡單2台、普通3台、困難4台消防車；5秒後從火場250～300公尺外的道路分方向進場，也要走真實道路及佈線，不會瞬間插旗。
- 黃色是未佔領、綠旗是自己、灰旗是其他消防車；消防車前往的目標閃紅框。
- 成功佔領得1分；15秒內再完成佔領可連擊，第二次起每次多1分；在已出動消防車30公尺內搶先完成再加1分，可與連擊疊加。
- 星等看實際佔領比例：未滿30%一星、30%～未滿60%二星、60%以上三星；最高總分依難度分開保存在本機。
- 走路每秒3公尺、跑步每秒6公尺；手機預設看80公尺寬，電腦175公尺，縮放50～250公尺。
- 碰撞半徑改為0.6公尺，人物與陰影大小不變；開局等周邊建物載入，卡進建物或持續推牆1.5秒會拉回可站道路，施工時不觸發。
- 跑步動畫加速、腳下揚塵與鏡頭前帶可在設定分別關閉，不影響速度或搶栓判定。
- 設定可關音樂及調整縮放，轄區地圖可看位置；兩者都不會暫停倒數。開場及結算保留「回 Z-TEAM 勤務模擬」。
