# 犀牛搶水源 v2

五分鐘內搶先插旗，和消防車競逐附近水源。v2 分三批交付；**已驗範圍、尚未完成與原樣截圖，以 preview 的交驗頁為準**，不能把本文件的玩法規格當作全部已完成。

## 三批範圍

1. **真資料＋開局＋火場**：依分隊抽真實場所、出勤任務卡、首次三步教學、建物吸附與火場動畫；卡片、教學、開場鏡頭全部結束才開始300秒。
2. **佈水線＋NPC＋難度**：近3公尺施工、取消與搶線、1／2／3台消防車；固定20局真資料模擬及普通難度平衡。
3. **爽感＋結算**：連擊／截胡、音效與飄字、按難度儲存最高分、手機結算與版面；最後才做桌機及手機模擬各一次正常五分鐘驗證。

## 操作

- 電腦：方向鍵／WASD走路，按住Shift或空白奔跑。
- 手機：左搖桿控制方向及幅度；**推搖桿並按住右側「跑」**才會奔跑。放開跑鍵恢復走路，放開搖桿即停。
- 設定內可靜音；「＋／−」調整視野，「轄區地圖」查看全區道路。開地圖不暫停倒數或消防車。
- 佈線玩法於第二批交驗：目標3公尺內開始施工；水帶條數為火場直線距離除20公尺無條件進位、至少1條，每條0.5秒，只有施工時間上限6秒。取消不保留進度。
- 連擊、截胡與星等於第三批交驗。星等只看佔領比例，不能以加分充當佔領。

本機啟動：`python3 -m http.server 8766 --bind 127.0.0.1`，開啟 <http://127.0.0.1:8766/>。只供本機開發；對外preview需使用白名單靜態目錄，不直接公開整個開發目錄。

## 本機流程快轉

本機網址加 `?test=1`，畫面顯示「本機測試 ×5」，以五倍速跑流程。只有精確的 `localhost`、`127.0.0.1` 或IPv6 loopback hostname可啟用；未加參數仍為正常五分鐘。

公開preview、正式網址與區網IP都不啟用快轉，即使帶 `?test=1` 仍為300秒。不改全域時鐘、固定玩法規則或碰撞半徑；最後桌機／手機交驗另以正常速度實跑，不能拿快轉或單元測試充數。

## 真資料與公開欄位

直接採用獲授權、已清理的 `zteam-rpg-handoff/data-v2/`，**不讀取、不搜尋原始CSV，不提供假資料備案**。

| 資料 | 公開格式與範圍 |
|---|---|
| `data/sites.json` | 1217筆場所；僅 `n, addr, use, st, x, y, q`。店名、地址及用途經使用者同意顯示。 |
| `data/w/index.json` | 180個水源格鍵；格邊長500公尺。 |
| `data/w/X_Y.json` | 合計5358筆；每筆只有 `[x,y,kind]`。種類僅 `hydrant,tank,pool,natural,other`，不公開水源地址、列管編號或水源編號。 |

- 沿用地圖座標：x向東、y向北，1 unit＝1公尺；不修改原始座標或既有道路／建物。
- 一般分隊只抽 `st` 相同的場所；復興、永吉抽以分隊座標為中心2500公尺內、非自身所屬的「周邊支援」場所，不生造轄區資料。
- 場所原定位為門牌推算；40公尺內有建物則吸附至最近建物中心，否則保留原座標。最近20個、300公尺範圍、佈線、箭頭及結算距離，皆從同一個火場中心計算。
- 每題僅取300公尺內最近20個水源，不足就用現有數量，不擴圈；只載入附近水源格。提示名稱由遊戲路名及種類產生，種類不另加分。
- 舊版虛構資料只保留於 `tests/fixtures/v1-*.json` 作回歸測試，不是可切換的遊戲資料或備案。舊轉檔器僅為既有工具測試，不用於匯入本次資料。
